# 武汉吊车出租｜武汉嘉豪起重吊装有限公司

武汉嘉豪起重吊装有限公司（对外品牌：武汉吊车出租｜嘉豪吊装）提供武汉汽车吊出租咨询，以汉阳区为重点，服务武汉经开区（沌口）、蔡甸区、硚口区、东西湖区、江岸区、江汉区、武昌区、洪山区和江夏区。武汉市内跨区需求，以及向周边延伸约10—30公里的项目，均可联系确认车辆与档期。

名称说明：部分旧地图商户资料仍显示“武汉嘉豪起重吊装有限公司”；本页面按当前营业执照名称“武汉嘉豪起重吊装有限公司”展示。

公司只安排汽车吊。可咨询 8 吨、25 吨、35 吨、50 吨、80 吨、100 吨、130 吨、200 吨、300 吨、500 吨和 800 吨需求。吨位表示可询需求，不代表每个吨位均有现车；车辆来源、具体吨位、档期、现场适用性和报价均按每单情况确认。

公开报价口径：按汽车吊吨位、作业时长、进退场距离、吊装半径、现场条件、车辆来源与档期逐单核实；联系周经理确认当单价格。
